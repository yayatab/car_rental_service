# db_choice

nosql/sql:

this application needs indexing and relational data. (i.e. which user rentec which car). hence: rdbms.

which to choose from oracle/mysql/postgresql/mssql:

i chose mysql because:
1. mysql is a lightweight and easy to use and manage
2. replaced easily with oracle-db/postgresql.
3. postgresql is more robust, and has more features that we don't need. (i.e. jsonb queries. and plugins)
4. easily scalable
5. becuase we use ORM, the transition is easy.
6. mysql is open source and mssql/oracle are propriety.
